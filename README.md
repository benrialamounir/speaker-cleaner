# Speaker Cleaner

Free online tool that plays calibrated tones to help clear water and dust from phone speakers.

**Runs entirely in your browser · No data collected**

## Features

- **Water mode** — Low-frequency pulse (165 Hz) best for ejecting water
- **Dust mode** — Steady mid-tone (220 Hz) to loosen dust and lint
- **Full mode** — Frequency sweep combining both

## How to use

1. Open `index.html` in a browser (or visit the GitHub Pages site)
2. Remove any case, speaker facing down over a soft cloth
3. Turn media volume all the way up
4. Choose a mode and press **Start cleaning**
5. Let the cycle finish. Wait 20–30 sec before repeating
